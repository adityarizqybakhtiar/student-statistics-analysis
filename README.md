# Student Statistics and Data Analysis Project

This repository contains an academic statistics and data analysis project completed as part of the Statistics and Data Analysis course at Universitas Mikroskil.

## Project Overview

This project analyzes questionnaire data related to student learning motivation and perceived course difficulty among Information Systems students. The analysis focuses on organizing survey data, converting score intervals into categorized values, and applying descriptive statistical methods to interpret the results.

## Objectives

- Analyze student learning motivation based on questionnaire data.
- Examine students' perceived difficulty of course materials.
- Apply descriptive statistical analysis to summarize the data.
- Present the results using frequency distributions, tables, and charts.

## Methods Used

- Questionnaire data analysis
- Data categorization
- Frequency distribution
- Mean
- Median
- Mode
- Data visualization using charts
